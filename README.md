# Anvar_Zokhidov_market_analysis
# Census Income & Market Segmentation Analysis

### Project Overview
This project uses U.S. Census Bureau data to predict high-income earners ($>50k) and segment the population into actionable marketing personas. 

### Key Features
- **Classification:** Population-weighted Logistic Regression optimized for ROC-AUC.
- **Segmentation:** K-Means clustering ($K=5$) visualized via UMAP and t-SNE.
- **Business Impact:** Identified 3 primary life-stage segments representing 342M citizens for targeted retail marketing.

### Files in this Repository
- `Market_Segmentation_Analysis.ipynb`: Full technical implementation and data cleaning.
- `JPMC_Anvar_Zokhidov_Report.pdf`: Executive report with business insights and strategic recommendations.
- `requirements.txt`: Environment dependencies.
